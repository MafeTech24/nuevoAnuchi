# Lic. Ana Paris — Sitio Web Profesional

Sitio web profesional de la **Lic. Ana Cristina Paris**, Psicóloga (UNC) y Doula. Presenta su atención clínica individual de personas adultas, acompañamiento perinatal, trabajo en vínculos y codependencia, orientación a familias y el Programa Integral de Menopausia.

🌐 **Sitio Web:** [licenciadaanaparis.com](https://licenciadaanaparis.com)

## SEO / GEO / AEO

El archivo `index.html` incluye:

- **SEO:** Title, meta description, canonical URL, Open Graph, Twitter Card
- **GEO:** Tags de geolocalización para Córdoba, Argentina
- **AEO:** Schema.org completo — `Person`, `WebSite`, `Service` (x2), `FAQPage`, `BreadcrumbList`
- **og:image:** Imagen generada con foto de Ana (1200×630px) en `/assets/og-image.png`
- **robots.txt:** Permite acceso a Google, GPTBot, Claude-Web, PerplexityBot y Google-Extended
- **sitemap.xml:** Rutas principales y páginas temáticas con prioridades y fechas
- **llms.txt:** Contexto estructurado para modelos de IA generativa

- Taller virtual por Google Meet
- Cupo reducido por cohorte
- 3 meses / 12 encuentros de 90 minutos
- Nueva cohorte cada primer lunes del mes — 19:15 hs (Argentina)
- Primera sesión de claridad gratuita (20 min)

- Acompañamiento privado y personalizado
- Encuentros semanales de 60 minutos durante 3 meses
- Soporte directo lunes a viernes
